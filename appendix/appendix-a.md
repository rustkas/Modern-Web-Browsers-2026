# **Приложения А**

## Приложение А: Шпаргалка по всем Web API 2026
### Категоризация по функциональным возможностям

---

#### 1. СЕТЕВЫЕ API (ЗАПРОСЫ И ОБМЕН ДАННЫМИ)

*   **Fetch API / `fetch()`** — Основной стандарт для HTTP-запросов. Поддержка `AbortSignal`, потоковой обработки ответов (Streams API) и интеграции с `CacheStorage` .
*   **Navigation API** — Новый стандарт для управления навигацией в SPA. Заменяет `History API`, поддерживает перехват переходов, предзагрузку и управление состоянием прокрутки.
*   **WebTransport** — Альтернатива WebSocket с поддержкой мультиплексирования, низкой задержкой и работой через HTTP/3.
*   **WebSocket API** — Для постоянных двунаправленных соединений. Используется в чатах, играх и для стриминга данных в реальном времени .
*   **Server-Sent Events (SSE) / `EventSource`** — Для одностороннего стриминга данных с сервера. Идеально подходит для AI-чатов и логов благодаря простоте использования .
*   **Beacon API / `navigator.sendBeacon()`** — Для отправки аналитических данных перед закрытием страницы без задержек.

---

#### 2. API АУТЕНТИФИКАЦИИ И БЕЗОПАСНОСТИ

*   **WebAuthn API** — Стандарт для беcпарольной аутентификации с использованием биометрии, ключей доступа (Passkeys) и физических токенов (FIDO2). Ключевой драйвер роста безопасности в 2026 году .
*   **Permissions API** — Для запроса, проверки и отслеживания статуса прав доступа к функциям (геолокация, камера, уведомления).
*   **Federated Credential Management (FedCM)** — Замена сторонних куков для входа через соцсети. Обеспечивает вход без отслеживания пользователя между сайтами.
*   **Trust Tokens API** — Борьба с фродом и ботами без использования идентифицирующих файлов cookie.
*   **Crypto API / `SubtleCrypto`** — Криптографические операции на уровне браузера: хеширование (SHA), генерация ключей, шифрование (AES-GCM) и работа с сертификатами.

---

#### 3. API РАБОТЫ С ПОТОКАМИ И ПАРАЛЛЕЛИЗМОМ

*   **Web Workers** — Выполнение тяжелых скриптов в фоновых потоках (Dedicated, Shared, Service Workers) .
*   **Service Worker API** — Прокси-сервер между браузером и сетью. Основа для PWA, офлайн-режимов, кеширования и фоновой синхронизации.
*   **Scheduler API / `scheduler.postTask()`** — Управление приоритетами задач внутри Event Loop. Позволяет помечать критические задачи (пользовательские клики) как высокоприоритетные.
*   **Atomics API & SharedArrayBuffer** — Для низкоуровневой работы с общей памятью между потоками Worker и WASM (требует изоляции сайтов).

---

#### 4. ГРАФИКА, МЕДИА И ВИЗУАЛИЗАЦИЯ

*   **WebGPU** — Современный API для рендеринга 3D-графики и выполнения высокопроизводительных вычислений на GPU (GPGPU). Пришел на смену WebGL. Работает на Vulkan, Metal и DirectX 12.
*   **WebGL 2.0** — Более старый, но широко поддерживаемый стандарт для 2D/3D-рендеринга.
*   **WebCodecs API** — Низкоуровневый контроль над кодированием и декодированием видео и аудио. Используется в редакторах и конференц-связи.
*   **WebXR 2.0** — API для дополненной (AR) и виртуальной (VR) реальности. Включает трекинг рук и пространственное позиционирование.
*   **Canvas 2D API** — Базовый API для рисования графики на холсте (поддерживает OffscreenCanvas для рендеринга в воркерах).
*   **CSS Typed OM** — Работа со стилями через объектную модель вместо строк, что повышает производительность анимаций.

---

#### 5. ХРАНЕНИЕ ДАННЫХ (СТОРАДЖ)

*   **Origin Private File System (OPFS)** — Эксклюзивный доступ к файловой системе для высокопроизводительных операций (чтение/запись). База для SQLite в браузере.
*   **File System Access API (FS Access)** — Доступ к нативной файловой системе пользователя (открытие/сохранение файлов через диалоги системы).
*   **IndexedDB 3.0** — Асинхронная ключ-значение база данных для хранения больших объемов структурированных данных (включая бинарные).
*   **CacheStorage / `caches`** — Специализированное хранилище для пар `Request` / `Response`. Используется Service Worker'ами для кеширования ресурсов.
*   **Web Storage API** — `localStorage` и `sessionStorage` для простого строкового хранения (имеет квоту ~10 МБ на источник) .
*   **Storage Manager API / `navigator.storage`** — Для оценки свободного места, управления квотами и запроса сохранения данных.
*   **Blob & File API** — Работа с бинарными данными и файлами, загруженными пользователем.

---

#### 6. ИИ, МАШИННОЕ ОБУЧЕНИЕ И ВЫЧИСЛЕНИЯ

*   **WebNN (Web Neural Network API)** — Специализированный API для запуска моделей машинного обучения прямо в браузере с аппаратным ускорением (NPU/GPU). Для ONNX и TensorFlow Lite.
*   **WebAssembly (WASM) 2.0 & Component Model** — Выполнение нативного кода (C++, Rust, Go) в песочнице браузера с высокой производительностью. WASI добавляет системный интерфейс.
*   **Web Audio API** — Для создания и обработки звука в реальном времени (синтез, микширование).
*   **MediaPipe / Face Detection API** — Встроенные возможности браузера для детекции лиц, распознавания жестов (без внешних библиотек).

---

#### 7. API УСТРОЙСТВ И ИНТЕРФЕЙСОВ

*   **Geolocation API** — Определение местоположения пользователя.
*   **Battery Status API** — Информация об уровне заряда аккумулятора (для оптимизации энергопотребления приложениями).
*   **Screen Orientation / WakeLock API** — Управление ориентацией экрана и запрет на переход в спящий режим.
*   **Vibration API** — Управление вибромотором (мобильные устройства).
*   **WebHID API** — Подключение и взаимодействие с нестандартными USB/HID-устройствами (геймпады, периферия).

---

#### 8. ПРОИЗВОДИТЕЛЬНОСТЬ И НАБЛЮДАЕМОСТЬ

*   **Performance API / PerformanceObserver** — Сбор метрик времени загрузки, рендеринга и выполнения скриптов (Core Web Vitals: LCP, INP, CLS) .
*   **ResizeObserver / IntersectionObserver / MutationObserver** — Наблюдение за изменениями размеров элементов, попаданием в область видимости и изменениями в DOM.
*   **Reporting API** — Автоматическая отправка отчетов о нарушениях политик безопасности (CSP) и деградации производительности.
*   **User Timing API / `performance.mark()`** — Создание пользовательских меток для профилирования кода в DevTools.

---

#### 9. ПРОЧИЕ ВАЖНЫЕ API

*   **Web Locks API** — Получение эксклюзивного доступа к ресурсу (например, к файлу) между различными вкладками/воркерами, предотвращая состояния гонки.
*   **Payment Request API** — Упрощение оплаты через встроенные браузерные диалоги (Google Pay, Apple Pay).
*   **Clipboard API** — Чтение и запись текста, изображений и произвольных данных в системный буфер обмена (с проверкой прав пользователя).
*   **Fullscreen API** — Включение полноэкранного режима для элементов.
*   **Picture-in-Picture API** — Плавающее окно для видео поверх всех приложений ОС.
*   **Contacts API** — Доступ к списку контактов (мобильные браузеры).
*   **Web Serial API** — Работа с последовательными портами (COM, USB-Serial) для общения с Arduino и промышленным оборудованием.
*   **Web Bluetooth API** — Общение с низкоэнергетическими Bluetooth-устройствами (BLE).
